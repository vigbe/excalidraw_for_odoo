Excalidraw for Odoo

The Excalidraw virtual whiteboard as a chatter tool for every record. 100% self-hosted: the library and its fonts are vendored inside the module, so no external CDN is required.

  • Pencil button next to the paperclip in every record chatter (saved records, Odoo 19).
  • Picker for existing drawings + fullscreen editor; scenes reopen exactly where you left them.
  • Each drawing persists as editable .excalidraw-compatible JSON plus an automatic PNG render on the record.
  • Autosave: 45 s debounce, 60 s max latency, flush on close.
  • Built-in PNG / SVG export and scene file import.
  • User / Manager permission groups (Odoo 19 privilege system).

Note: version 19.0.2.0.0 replaces the former standalone Excalidraw app — see the README for the upgrade runbook.
