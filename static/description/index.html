Excalidraw for Odoo

The Excalidraw virtual whiteboard, embedded as a native Odoo application. 100% self-hosted: the library and its fonts are vendored inside the module, so no external CDN is required.

  • Draw hand-styled diagrams, flows, floor plans and sketches.
  • Scenes persist as editable .excalidraw-compatible JSON.
  • Automatic PNG previews in the list view.
  • Built-in PNG / SVG export and scene file import.
  • Chatter and activities on every drawing.
  • User / Manager permission groups (Odoo 19 privilege system).
